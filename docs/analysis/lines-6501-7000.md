## Findings

- Summary construction is closed. Brag submission hides `bragButton` and later enables it without showing it, whereas Back only hides the nested screen and enables actions; this visibility asymmetry is preserved behavior.
- `CheckSkill` encodes two award systems: probabilistic repeatable skill actions for types 1–5, and threshold-gated one-time Fun/Achievement awards for types ≥6. Forced awards bypass chance and add four points after any normal/special award path.
- `skillLimit` lowers the point cap from 450 to 375 and blocks the rank-five-to-six transition, while ordinary 450-cap profiles can reach rank six.
- The skill-list scroll frame again loses its intended first template because Lua `and` returns only `BackdropTemplate`.
- Skill refresh writes undeclared globals `foundFeat` and `itemID`. They are scratch values, not persisted schema, but their global leakage and cross-call visibility are defect evidence.
- Section content is preallocated from complete skill data, then refresh hides everything and repopulates only currently relevant entries in reverse data order.
