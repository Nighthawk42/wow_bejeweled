## Control flow and data flow

- `ht` is now complete: it updates current score, emits one-time classic thresholds, performs level/multiplier presentation when maximum score is reached, marks `leveledUp`, and always refreshes the bar inside the `maxScore` gate.
- `Tt`, `Bt`, `xt`, `rt`, `kt`, `Ft`, and `Pt` form a cohesive level/timer bar method set. Mode `c` is definitively classic; mode `k` is a flight-learning mode. `ae` remains the likely ordinary timed mode, but its direct branch is not yet observed.
- Classic progression uses a 0–500 score interval. Other modes scale maximum score by `Ce[mode]`; batch 02 proves this table is a per-mode score-range multiplier.
- `X`/`x` are inverse base-70 transforms for fixed-width values, with optional centered signed range. The digit alphabet is nonstandard and intentionally preserved.
- The first `H` produces five decimal checksum digits; `P` prefixes their packed base-70 representation; `fe` verifies and strips it. A second shadowing `H` reduces a string to a byte sum for per-name checksum seeds.
- Lua lexical capture is behavior-critical: functions declared before the `P`, `H`, and `j` shadow declarations keep the older bindings. Flattening or reordering helpers could silently break the codec.
- `j` mutates a fixed ten-row leaderboard in place. It validates inbound scores, optionally removes lower duplicates, maintains PopCap filler rows, inserts qualifying scores, and can award a “beat another player” achievement.
- `_t` owns game-over score presentation, personal-best persistence, leaderboard merge, publishing, result-HUD updates, and first-game popup behavior. Network payload is `rank .. playerName .. "*" .. authenticatedScore`.
- `M` begins match scoring. Match length, combo count, power/special flags, and a special-type discriminator contribute to points and skill checks; remaining parameters and downstream score application await batch 03.

| Publish payload | Decimal rank text + player name + `*` + authenticated score. Parser behavior is outside this batch. |
| Match score prefix | `T[combo]` plus length bonus (4→10; ≥5→20), optional power flag bonus 25, then special bonus 75 or 20. |
