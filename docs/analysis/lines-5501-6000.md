## Findings

- Main-window mouse reentry is the inverse of Batch 11's mouse-away path: it restores fade/sound state and only calls `T(false)` when the pause was mouse-owned and the summary is fully opaque.
- Menu `keepScreen` is a one-hide handoff flag. It prevents both unpause and sub-screen cleanup while control moves from the menu to another screen.
- Popup layout is inferred from color escape text rather than an explicit popup type. Its assignment from undeclared `obj` is an implicit-global dependency and likely defect evidence; no declaration has appeared through line 6000.
- Mode-window `gameMode` fields are transition guards, not the global gameplay mode: they distinguish intentional forward navigation from closing/back navigation.
- The classic buttons' global frame names are opposite their visible labels and actions. This mismatch is preserved evidence, not a rename signal.
- Flight initialization currently displays a fixed two-minute estimate even though timer state receives `flightTime or 0`; the original dynamic display survives only as a comment.
